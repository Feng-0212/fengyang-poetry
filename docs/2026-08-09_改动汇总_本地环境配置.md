## 三、踩坑记录

1. **Upstash token 两次无效**：首次 token 解码含非法字符（`02H86` 中的 `H` 非 hex），服务器返回 WRONGPASS。正确 token 解码为纯 hex 结构。教训：Upstash REST Token 请从控制台「复制」按钮获取完整值，勿手打。
2. **概念澄清**：AI_TEXT_MODEL / AI_IMAGE_MODEL 是指定模型（"点菜"），AI_API_KEY 是调用凭证（"会员卡"），两者缺一不可；两个模型共用一个 Key。
