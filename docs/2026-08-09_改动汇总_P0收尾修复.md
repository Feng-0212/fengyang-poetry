## 二、关键发现（AI 配图裂图根因）

1. **下载超时过紧**：agnes 生图 CDN 实测下载需约 20 秒，原 15s 超时必然失败 → 一直退回第三方 URL（过期即裂图）。
2. **dataURL 超限风险**：1.4MB 原图 → base64 约 1.87MB，超过 Upstash 免费版单 key 1MB 限制，直接存 Redis 会失败。
3. **URL 短命**：实测刚生成的 agnes URL 约 20 分钟内过期——裂图问题真实存在且影响面大。
