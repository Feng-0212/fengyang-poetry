## 1. 产品概述

### 1.1 一句话定位
**墨韵阁是一座随节气流转的私人诗词收藏楼**——把「记录诗词」做成一件事雅致的事：以「藏」为单元组织，以节气为时间轴，以 AI 为助手，以水墨为美学。

### 1.2 产品背景
- 作者有收藏/创作诗词的需求，现有工具（笔记类）缺乏诗词专属的组织与展示。
- 从「四时墨苑」（单藏、24 节气）演进为「墨韵阁」（多藏并行），形成 6 个预置主题藏 + 任意自建藏。
- AI 能力（赏析/配图/标签/语义搜索）已接入，降低收藏与整理成本。

### 1.3 产品目标
| 目标 | 衡量 |
|------|------|
| 让收藏诗词成为享受而非负担 | 写一首诗 ≤ 3 步（选藏 → 填写 → 保存） |
| 让找诗快 | 搜索覆盖标题/正文/标签/拼音/语义，⌘K 全站唤起 |
| 让藏诗有仪式感 | 节气流转、印章、水墨、卷轴、分享壁纸 |
| 让数据不丢 | Redis 持久化 + 每日备份 + 30 天快照 + 导出 |
| 让 AI 成为贴身书童 | 赏析/配图/打标签/语义检索全链路 |

### 1.4 目标用户（当前）
- 单人使用者（作者本人）——私人诗词库，单用户模型。
- 次要：来访者（浏览公开页/分享卡片，只读）。

## 3. 功能需求

### 3.1 藏（Collection）体系

**FR-1 多藏组织**
- 预置 6 藏：四时墨苑（🌸 朱砂红）/ 月下山河（🏔️ 青绿）/ 关山词（⚔️ 赭石）/ 烟雨阁（🌧️ 靛蓝）/ 童心斋（🪁 蜜橘）/ 新诗林（🌲 松绿）。
- 每藏属性：主名、副标、一句诗化简介、印章单字、图标、主色/副色/背景关键词、布局（classic/list/gallery）、是否为系统藏。

**FR-2 自建藏**
- 用户可创建任意新藏（自定义名称/颜色/印章/布局）。
- 系统藏不可删除；自建藏可删除（连带删除其下诗词）。

**FR-3 藏主页**
- 展示藏的主题色、印章、简介、诗词列表（按布局切换）。
- 四时墨苑有增强版：节气导航 + 季节视图 + 书签页 + 回收站。

### 3.2 诗词（Poem）

**FR-4 诗词 CRUD**
- 创建：标题、作者（默认佚名）、朝代、正文、注释（随笔）、藏、节气（可选）、标签（可选）。
- 编辑 / 软删除（进回收站）/ 恢复 / 永久删除。
- 收藏：切换 isFavorite（单用户语义）。

**FR-5 写诗流程**
- 路径：写诗入口 → 选藏 → 表单填写 → 保存；或藏内直接写。
- ⌘Enter 快捷提交。

**FR-6 诗词详情**
- 展示正文（可切换卷轴展开动效）、作者/朝代、节气徽章、标签、收藏数、AI 赏析、AI 配图、注释。
- TTS 朗读按钮（5 音色可切）。

### 3.3 节气系统

**FR-7 24 节气**
- 全量 24 节气元数据：名称/英文/季节/日期范围/颜色/意象/背景动画（雪/雨/叶/萤/瓣/无）。
- 自动识别当前节气（按日期），驱动主页色调与氛围。

**FR-8 节气诗库**
- 四时墨苑下「节气诗库」：按节气浏览诗词，全年无空洞。
- 每首诗词可关联节气，按季筛选。

### 3.4 搜索

**FR-9 搜索能力**
- 模糊搜索（Fuse.js）：标题/正文/注释，权重分级。
- 拼音搜索：全拼（jingyesi）与首字母（jysm），按需加载。
- AI 语义搜索：自然语言（"思乡的诗"），AI 理解后推荐。
- 筛选：6 藏 × 4 季组合；分组：按藏/按季/平铺。
- 实时高亮查询词；最近 5 次历史；URL 同步（/search?q=月）。
- 快捷键 ⌘K 全站唤起快速搜索弹窗。

### 3.5 AI 能力

**FR-10 AI 赏析**
- 对单首诗词生成深度赏析（意境/手法/情感）。
- 结果缓存 30 天（Redis），不重复计费。
- 支持自定义 API Key / Base URL / 模型。

**FR-11 AI 配图**
- 两步生成：文本模型生成绘画提示词 → 图像模型生成封面。
- 结果存 coverImage（dataURL 或 URL）；主模型失败自动换备选模型；全部失败回退图池（14 张水墨 SVG）。

**FR-12 AI 标签**
- 单首智能打标签（18 个预定义标签池）。
- 批量打标签：全库或选中诗批量执行，逐首进度反馈。

**FR-13 安全**
- AI 接口限流：每 IP 20 次/分钟（Redis 滑动窗口），429 + Retry-After。

### 3.6 数据与备份

**FR-14 持久化**
- 主存储 Upstash Redis；IndexedDB（Dexie）离线降级，双写兼容。
- 写入经服务端鉴权（POEM_PASSWORD，本地 dev 放行）。

**FR-15 备份**
- 每日自动快照（Vercel Cron 19:00），保留最近 30 天（TTL），维护索引。
- 手动触发：`GET /api/backup?key=<CRON_SECRET>`。
- 快照历史查询/下载（/api/backup/history）。
- 异地容灾（可选）：BACKUP_REMOTE_URL 推送，失败不阻断。

**FR-16 导入导出**
- 导出：JSON 全量备份；诗集导出 Markdown / TXT / 打印 PDF。
- 导入：JSON 批量恢复。

### 3.7 展示与互动

**FR-17 布局**
- 藏内三种布局：经典 / 列表 / 画廊。

**FR-18 分享**
- Canvas 生成诗词壁纸卡片（印章/节气/背景，三尺寸三风格），可下载分享。

**FR-19 诗词接龙**
- 随机起句 → 接龙（上一句末字 = 下一句首字）→ 计分评语；52 句经典名句库。

**FR-20 统计**
- 写作热力图（按日）、标签词云、季节分布、趋势。

**FR-21 标签体系**
- 自由标签 + AI 智能标签池（18 预定义）；标签总览页（云 + 热门榜）。

**FR-22 回收站**
- 软删除 30 天自动清理；全藏共享回收站，可恢复/永久删除。

### 3.8 体验与工程

**FR-23 主题**
- 水墨基底、宣纸纹理、暗色模式、字号调节（CSS 变量）。

**FR-24 PWA**
- 可安装（manifest + icons）、Service Worker 离线缓存、加入主屏。

**FR-25 朗读（TTS）**
- 微软 Edge 神经网络中文音色（5 种）；预生成静态音频 + Redis 缓存 + 浏览器 Web Speech 降级。

## 4. 非功能需求

| 类别 | 需求 |
|------|------|
| 性能 | First Load JS ≤ 200KB/页；首屏可交互 ≤ 3s（4G）；列表滚动 60fps |

| 兼容 | 桌面/平板/手机三端；现代浏览器（Chrome/Safari/Edge/Firefox） |
| 可维护 | TypeScript 全量类型；目录分层（app/components/hooks/lib/types）；docs/ 留档机制 |
| 部署 | Vercel + GitHub Actions 自动部署；Cron 每日备份 |

## 5. 用户故事（示例）

- 作为用户，我打开网站时首页根据当前节气自动换色调和氛围文案。
- 作为用户，我按 ⌘K 输入"jingyesi"能秒出《静夜思》。
- 作为用户，我写了一首诗想让 AI 赏析并配图，一键生成，无需懂提示词。
- 作为用户，我把诗移到回收站 30 天后它自动消失，不用担心误删。
- 作为用户，我导出 JSON 存档，换设备后导入即恢复。
