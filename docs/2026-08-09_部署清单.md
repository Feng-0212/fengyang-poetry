**用途**: P0-2「生产部署凭据就绪」的执行清单。本地 `.env` 已配置（AI 四件套 + Redis），以下为 Vercel 生产部署需补齐的部分。

## 一、Vercel 环境变量配置

在 Vercel 项目 → Settings → Environment Variables 添加（**Production** 环境；AI/Redis 凭据可从本地 `.env` 复制）：

| 变量 | 必需 | 说明 |
|------|------|------|
| `POEM_PASSWORD` | ✅ 必填 | 写操作密码。**安全关键**：必须非公开、非 `NEXT_PUBLIC_*`。未配置则生产写操作全部 503（保护生效但功能不可用） |
| `UPSTASH_REDIS_REST_URL` | ✅ | Upstash Redis REST 地址（本地已用同一份） |
| `UPSTASH_REDIS_REST_TOKEN` | ✅ | Upstash Redis REST Token（注意：从控制台「复制」按钮获取完整值，勿手打） |
| `AI_API_KEY` | ✅ | AI 文本模型 Key |
| `AI_BASE_URL` | ✅ | AI 接口地址（如 `https://apihub.agnes-ai.com/v1`） |
| `AI_TEXT_MODEL` | ✅ | 文本模型名（如 `agnes-2.0-flash`） |
| `AI_IMAGE_MODEL` | 可选 | 图像模型名（如 `agnes-image-2.1-flash`），留空复用文本配置 |
| `AI_IMAGE_API_KEY` / `AI_IMAGE_BASE_URL` | 可选 | 图像独立 Key/地址，留空复用 `AI_API_KEY`/`AI_BASE_URL` |
| `CRON_SECRET` | 建议 | 每日备份接口鉴权（配合 Vercel Cron 调用 `/api/backup`） |
| `NEXT_PUBLIC_SITE_URL` | 建议 | 站点正式域名（影响 OG 链接与元信息），如 `https://poetry-garden.vercel.app` |
| `BACKUP_REMOTE_URL` / `BACKUP_REMOTE_TOKEN` | 可选 | 异地容灾推送端点（未配置维持同库快照） |

**已配置项**（本机 `.env` 有值，Vercel 需手动同步）：UPSTASH_REDIS_REST_URL/TOKEN、AI_API_KEY、AI_BASE_URL、AI_TEXT_MODEL、AI_IMAGE_MODEL。

## 二、Vercel Cron（每日备份）

1. 项目 → Settings → Cron Jobs → Add
2. Cron 表达式：`0 2 * * *`（每天 02:00 UTC）
3. 请求路径：`/api/backup?secret=<CRON_SECRET 值>`
4. 若 Cron 不可用：也可部署后手动 `curl -X POST https://<域名>/api/backup?secret=<CRON_SECRET>`
