## 测试中发现并修复的问题

### `/api/backup/history` 无 Redis 时 500

- **现象**：`GET /api/backup/history` 返回 `500 {"error":"no kv"}`，而 `/api/backup` 正常 200。
- **根因**：`backup/history/route.ts` 使用**私有 `getKv()`**（无内存回退，环境变量缺失返回 null → 500）；`backup/route.ts` 使用 `lib/kv.getKv()`（含内存回退）。两路由行为不一致。
- **修复**：`backup/history/route.ts` 改用 `lib/kv.getKv()`，与 backup 路由及全项目 AI 路由一致。
- **复测**：无 Redis 环境返回 `200 {"history":[]}`，生产有 Redis 时行为不变。
- **涉及文件**：`src/app/api/backup/history/route.ts`

## 部署注意（沿用修复总结）

- ⚠️ 部署前必须配置非公开环境变量 `POEM_PASSWORD`（服务端不再接受 NEXT_PUBLIC 密码）。
